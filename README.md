# 2048 Web

A lightweight browser-based 2048 puzzle game built with HTML, CSS, and vanilla JavaScript.

## Features

- Classic 2048 sliding and merging gameplay
- Keyboard and touch controls
- Multiple challenge levels
- Score and best-score tracking
- Progress saved locally in the browser
- Responsive layout for desktop and mobile

## Project Structure

```text
2048-web/
├─ index.html
├─ css/
│  └─ style.css
└─ js/
   └─ game.js
```

## Run Locally

Open `index.html` directly in a modern browser.

No installation or build process is required.

## Controls

- Desktop: Arrow keys or WASD
- Mobile: Swipe in any direction
- Restart: Select the Restart button

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Deployment

This project can be deployed as a static website using GitHub Pages.
